# Session Log — 2026-11-18 (PDF/Word Resume Import, Smart Profile Sync, Justify & Optional Company)

## Focus Goal
Ship `v1.0.4` minor release:
1. Enable users to upload existing `.pdf` and `.docx` (Word) resumes via a native `<dialog>` panel in both **Resume Studio** and **My Profile**, extract full `StructuredResume` + Smart Profile data, save to Supabase, and edit immediately in Resume Studio.
2. Replace `[hyphens:auto]` in Resume Studio **Justify** mode with hyphen-free whole-word justification (`[hyphens:none] [word-break:normal] [overflow-wrap:break-word] [text-justify:inter-word] [text-wrap:pretty] [text-align-last:left]`).
3. Make **Company** optional in **Save New Resume Version** (`A4ResumePreview.tsx`, `ResumeVersionsDrawer.tsx`) and sync saved edits directly to `public.user_profiles` via `POST /api/resumes/history` (`syncToProfile`).

## Verification & Release
- `npx tsc --noEmit`, `npm run lint`, and `npm run build` passed.
- Supabase schema (`supabase/schema.sql`) already contains all required columns (`user_profiles.profile_data`, `user_profiles.full_name`, nullable `tailored_resumes.company`, and `resumes` Storage bucket).
