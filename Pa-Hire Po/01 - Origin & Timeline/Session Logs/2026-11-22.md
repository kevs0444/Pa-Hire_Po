# Session Log — 2026-11-22 (Dynamic Certification Rows & Columns in Resume Studio AI & Obsidian `AGENTS.md` Folder)

## Focus Goal
Ship `v1.0.7` adding dynamic row & column controls to the Certifications section in **Resume Studio (`AI`)** and organizing root `AGENTS.md` into a dedicated Obsidian Second Brain folder linked from `00 - Home MOC.md`:
1. **Dynamic Certifications Grid Data Model & Helpers (`src/types/resume.ts`, `src/features/resume/lib/resume-links.ts`):**
   - Added `ResumeCertificationColumns = 1 | 2 | 3` and optional `certificationColumns?: ResumeCertificationColumns` on `StructuredResume` (defaulting to `2` for backward compatibility and preserved by `...base` spreads in `tailorResumeLocally` and `/api/resume/tailor`).
   - Added `clampCertificationColumns()` and `swapCertificationUrls()` so reordering certifications preserves paired credential URLs.
2. **Dynamic Row & Column Controls in Resume Studio (`src/features/resume/components/A4ResumePreview.tsx`):**
   - Added explicit `CERTIFICATION_GRID_CLASS` Tailwind v4 grid tracks (`grid-cols-1`, `grid-cols-2`, `grid-cols-3`) applied identically to preview and `@media print` PDF export, with `min-w-0` child guards preventing horizontal overflow in 3-column mode.
   - Added edit-mode `no-print` header controls: tabular `Cols × Rows` readout, **`+ Add Row`** (appends `certColumns` entries), **`+ Add Column`** (expands `1 → 2 → 3` and fills to `nextCols` if needed), **`- Col`** (narrows `3 → 2 → 1` non-destructively), and **`Add Certification`** (adds 1 entry), plus `↑`/`↓` per-item reordering synced with `swapCertificationUrls`.
3. **Obsidian Vault `AGENTS.md` Folder (`Pa-Hire Po/07 - Agent Rules & Guidelines/` & `00 - Home MOC.md`):**
   - Kept root `AGENTS.md` in place for automatic agent/Next.js loading and created `07 - Agent Rules & Guidelines/` with `00 - AGENTS Rules Index.md`, `Agent Rules - UI Design System & Anti-AI-Slop Mandate.md`, `Agent Rules - Resume Studio, Profile Media & Supabase Lock.md`, and `Agent Rules - Persistent Memory & Pre-Post-Push Gate.md`, all linked from `00 - Home MOC.md`.
4. **1:1 A4 Preview-to-PDF Export & `Fit 1 Page` Auto-Scaling (`src/features/resume/lib/resume-print.ts`, `globals.css`, `A4ResumePreview.tsx`, `ResumeFormatToolbar.tsx`, `ApplyFlowModal.tsx`, `SubmittedResumeModal.tsx`):**
   - Eliminated `@media print` `9.5pt` (`12.67px`) font inflation and inline `.resume-sheet-containment` height locks in `globals.css`.
   - Centralized physical page dimensions, density typography metrics (`10.2px`/`11px`/`11.5px`), `resolveFitOnePage()` (ON by default for A4/Letter/Legal via `fitOnePage?: boolean`), `computePrintLayoutSummary()`, and `buildResumePrintStyles()` (`zoom` 1-page scaling + `@supports not (zoom: 0.9)` fallback).
   - Added `[data-resume-content="true"]` `ResizeObserver` measurement, `no-print` dashed Page 1 boundary indicator, toolbar `Fit 1 Page` toggle + live `✓ 1 Page` / `✓ 1 Page (Fit XX%)` / `⚠ N Pages` badge, Edit-Mode clean print safeguard (`beforeprint`/`afterprint` + `RESUME_PRINT_REQUEST_EVENT`), and full parity in `ApplyFlowModal` and `SubmittedResumeModal`.
